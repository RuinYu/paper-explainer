# 逐篇结构化提取模板

在写正文之前，先把每篇论文压成下面这份结构化记录。**不要跳过这一步直接写书稿**——横向比较表和第五部分的故事线都依赖这些字段，边读边写会导致口径不一致。

提取结果建议单独存成 `extraction.json` 或 `extraction.md`，与书稿 HTML 放同一目录，便于日后追加新论文时只更新差异。

---

## 单篇记录字段

```
1. 代号          第一作者+年份，如 Gu2024。全书统一用它指代，不再写全名
2. 题录          完整标题 / 第一作者 / 通讯单位 / 期刊 / 年份 / 卷期页 / DOI
3. 一句话问题    这篇要解决什么具体问题（一句话，必须含物理量或工艺约束）
4. 器件结构      层数 / 材料体系 / 结构类型 / 从端面到片上波导的完整结构链 / 各段长度与宽度
5. 模式转换机制  光场靠什么物理机制从光纤模场压缩到片上单模
6. 关键几何参数  参数名 | 数值 | 单位 | 出处（Fig./Table/正文页码）
7. 仿真方法      FDTD/FEM/EME/本征模求解器、软件、PML、网格、收敛性检查
8. 实验方法      光纤类型 / MFD / 波长 / 测试结构 / 单端还是双端 / 如何扣基准
9. 核心性能      损耗（带口径）/ 效率 / 带宽 / PDL / 容差 / 尺寸 / 工艺兼容性
10. 创新点       分标【原理】【结构】【工艺】【表征】
11. 局限性       作者自述 + 我的判断（必须分开写）
12. 与他文关系   引用了谁、对比了谁、数据如何
13. 数据性质     实测 / 纯仿真 / 仿真+少量实测
14. 存疑点       内部矛盾、缺失字段、无法确认的表述
```

---

## 各字段的写法要求

### 1. 代号
用“第一作者姓氏+年份”。两篇同姓同年时加名字首字母。代号一旦确定，全书（含图表、对比表、目录）统一使用。

### 2. 题录
- 期刊名写全称，缩写放括号里
- 卷(期):起页 或 DOI，二者至少给一个
- **原文缺失的字段如实写“原文未标注”**，不要根据文件名反推期刊名。若只能从文件名推断，标注“据文件名推断，待核实”

### 3. 一句话问题
反例：「提高耦合效率」
正例：「在不使用亚 100 nm 线宽的前提下，把端面耦合损耗压到 1 dB 以内」

### 4. 器件结构
必须写成一条链：`光纤 → 端面 → [结构段1] → [结构段2] → 片上波导`，每段给长度与宽度。有数值给数值，没数值写“论文未报告”。
注明层数（单层/双层/三层）与每层材料及厚度，因为这是分组与横比的第一维度。

### 5. 模式转换机制
要能回答“凭什么模场会连续变小”。常见机制：
- 有效折射率渐变（宽度/厚度变化）
- 绝热演化（变化足够慢，模式不跳变）
- 超模耦合（多根波导靠倏逝场耦合，间距变化改变模式宽度）
- 亚波长等效介质（结构周期远小于波长，等效为均匀介质）
- 相位整形（超表面改变波前，而非改变折射率分布）
- 自由拓扑（逆设计，无解析机制，靠目标函数搜索）

### 6–7. 参数与仿真
参数表每行必须带出处。仿真部分重点记录**作者做了哪些可信性验证**：网格收敛、能量守恒、模式归一化、与解析解对比。多数论文没写，这本身就是可写的局限性。

### 8. 实验方法
必须记录的四件事，缺一项该篇损耗就不可与别篇直接比较：
1. 用什么光纤（普通 SMF / UHNA / 透镜光纤 / 光纤阵列），MFD 多少
2. 单端还是双端测量
3. 用什么结构扣掉波导损耗（cut-back / 参考波导 / 微环 / FP 腔）
4. 光纤-光纤基准怎么测的

### 9. 核心性能
损耗必须写成 `数值 + 口径 + 条件`，例如：
`1.18 dB/facet（双端实测折半，配 6.3 μm 解理 SMF，1550 nm，TE）`

只写 `1.18 dB` 的记录视为不合格，后续无法比较。

### 10–11. 创新点与局限性
创新点必须分类，因为“原理创新”和“工艺创新”的价值判断完全不同。
局限性分两栏：作者自述的、我判断的。**不能把我的判断混进作者的话里**，这是学术写作的底线。

### 12. 与他文关系
只有当论文明确引用并对比了某工作时，才写“对比了 X，数据为 Y”。
没有直接引用证据时，写“技术路线相似”，不要写“继承了”“改进了”。

### 13. 数据性质
三档：`实测` / `纯仿真` / `仿真+少量实测`。
这一列决定该篇能否进入“实测排序”。纯仿真论文在对比表里单独标注，不与实测值并排排名。

### 14. 存疑点
凡是遇到下面情况，一律记进这一栏：
- 正文与摘要/结论数值不一致
- 损耗扣除链条算不通
- 同一参数在文中出现两个值
- 图表标注与正文描述不符
- 关键参数缺失但结论依赖它

写清“哪一处、为什么不自洽、建议引用时怎么表述”，不要替作者圆。

## 批量处理建议

文件数 **≥2** 即并行提取，**按篇数均分**（8 篇分 3+3+2，余数给前面的组），每组一个子任务，各自输出上面 14 项 + 单篇核验三件套。结构路线（单层／多层／垂直锥化／超表面／逆设计）只作为 prompt 里的一行提示，帮子任务预判机制类型，**不作分组依据**。

均分而不是按技术路线分组的原因：并行墙钟由最慢的一组决定，按篇数切才切得平；而"同组内口径差异更好发现"这件事，本来就要在第 3 步的横向对比表里做，不需要靠分组来保证。

合并时必做四件事：
1. 检查代号是否唯一
2. 检查"数据性质"是否每篇都有
3. 检查三件套（口径结论／数据性质／存疑点）是否齐全，缺的退回该组补
4. 把各组 `【本篇内部矛盾】` 汇总成一张清单，逐篇分配进第四部分的「注意」段落；`【跨篇可比性】` 交给第 3 步统一判定

```
代号: Liang2022
题录: Efficient and Broadband Trident Spot-size Convertor for Thin-Film Lithium
      Niobate Integrated Device / Xuerui Liang / 光迅科技 / IEEE PTL 2023,
      35(1):35-38 / doi:10.1109/LPT.2022.3221195
一句话问题: 在单层 600 nm TFLN 上，用光刻可实现的线宽（≥100 nm）把 6.3 μm 光纤
            模场过渡到片上单模，同时覆盖 1490-1640 nm
器件结构: 单层 / X-cut LN 600 nm，脊高 300 nm，BOX 4.7 μm，PECVD SiO2 5 μm /
          结构链 光纤 → 端面 → 三叉波导（W4=1.95 μm 起） → 间距渐变至 W3=1.2 μm
          → 中间波导收窄 → 片上条波导；L1=300, L2=150, L3=300 μm
模式转换机制: 三根波导靠倏逝场耦合形成超模，间距变大→耦合变弱→模场变宽；
              中间脊波导先收窄把光推入 slab（LN rib taper 本身扩不了模场）
核心性能: 1.18 dB/facet（双端实测折半，6.3 μm 解理 SMF，1550 nm，TE）；
          最优 0.98 dB @1565 nm；1 dB 容差 ±3 μm（Z，TE）
数据性质: 实测
存疑点: 摘要写"±3 μm(Z) 和 ±2 μm(X)，for TE"，正文写"±3 μm Z for TE、X for TM"，
        两者不一致；引用时建议保守表述并注明原文不一致
```
